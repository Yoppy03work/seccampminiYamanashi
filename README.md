# 旅のしおり

旅行プランや旅の記録を、一般公開・仲間への共有・自分限定で保存できるWebアプリです。

セキュリティ・キャンプ2026ミニ（山梨開催）『生成AI時代のWebアプリケーション開発とセキュリティ』の演習用リポジトリです。

## 演習を始める

まず[環境準備ガイド（スクリーンショット付き）](docs/00-codespaces-setup.md)に沿って、GitHub Codespacesを起動してください。

準備ができたら、講師の案内に合わせて各手順を進めます。

- [アプリの起動・Semgrepでの検査](docs/01-start-and-scan.md)
- [Trivyでの依存関係の検査](docs/05-trivy.md)
- [Issueの作成・AIへの修正依頼](docs/02-issue-and-review.md)
- [CIでの検査の自動化](docs/03-ci.md)

[困ったときの代替手順](docs/04-fallback.md)

教材には学習用の脆弱性が含まれます。個人情報・秘密情報は入力せず、転送ポートはPrivateのまま利用してください。

## 反映したセキュリティ修正

このリポジトリでは演習の進行に合わせて、以下の修正を確認・反映しました。

- 公開プラン検索で SQL インジェクションを防ぐため、入力値を SQL 文字列へ直接埋め込まないようにしました。
- 公開プランの印刷見出しで、ユーザー入力をHTMLとしてそのまま出力しないようにしました。
- 旅行ガイドのダウンロードで、ガイドディレクトリ外へのアクセスを拒否するようにしました。

## CI の確認

GitHub Actions で `pytest` と `semgrep` を実行するワークフローを追加しています。
`pull_request` と `push` 時に自動実行されます。
